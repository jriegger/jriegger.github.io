Privacy Policy

Effective date: September 21, 2026

Purpose and users

Personal Workspace Connector is a private integration operated for a single user's personal automation. It is not available to the public and does not maintain public user accounts.

Google user data

When authorized by the sole user, the integration may access the Google Workspace data covered by the permissions shown on Google's authorization screen, including Gmail, Calendar, Drive, Docs, Sheets, and Contacts data. It uses that data only to perform actions requested by the user.

Storage and processing

Authorization credentials and working data are stored on systems controlled by the user. Data may be processed by infrastructure or AI service providers selected by the user solely to perform requested functions. This informational website does not collect Google user data.

Sharing and advertising

Google user data is not sold, used for advertising, or shared for unrelated purposes. Access is limited to the user and service providers acting only on the user's instructions.

Retention and deletion

Data is retained only as needed for the user's requested functions and is deleted under the user's retention controls. The user can revoke Google access at any time from their Google Account security settings.

Google API policy

Use of information received from Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements.

Contact

The support contact for this integration is the address displayed on its Google OAuth consent screen.
